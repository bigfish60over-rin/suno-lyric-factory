# SUNO LYRIC FACTORY

歌詞とSUNO用プロンプトの制作依頼文を作るPWAです。テーマ・ジャンル・雰囲気などを入力すると依頼文ができ、共有メニューやコピーでChatGPTやClaudeに渡せます。

公開URL: https://bigfish60over-rin.github.io/suno-lyric-factory/

## 未実装のこと

**ChatGPT・Claude・SUNO MCPとの直接連携は未実装です。**

- このアプリは依頼文のテキストを作り、共有またはコピーするだけです
- 外部サービスへの自動送信、歌詞や楽曲の自動生成は行いません
- できた依頼文は、利用者が各サービスの会話に貼り付けて使います

## 機能

- 楽曲のテーマ、ジャンル、雰囲気、ボーカル、長さ、言語、追加要望の入力
- 制作モードの切り替え（歌詞制作、ブラッシュアップ、Style Prompt、リミックス指示）
- ChatGPT向け依頼文の共有またはコピー
- Claude向け指示のコピー
- 設定の保存と初期化
- ホーム画面へのインストールとオフライン起動

## データの保存先

設定は端末のブラウザ内（localStorage の `sunoFactorySettings`）にだけ保存します。サーバーへの送信はありません。APIキーなどの秘密情報は使わず、このリポジトリにも含めません。

## オフラインで使える範囲

一度オンラインで開くと、アプリ画面と保存済み設定をオフラインで使えます。依頼文を貼り付ける先のサービスには通信が必要です。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面と処理 |
| `manifest.webmanifest` | インストール用の情報 |
| `sw.js` | オフライン用のキャッシュ |
| `icons/` | アプリのアイコン |

各ファイルの相対的な位置は変えないでください。

## GitHub Pagesでの公開

Settings > Pages で `main` ブランチの `/ (root)` を公開元にします。リポジトリ名を変える場合は、`manifest.webmanifest` の `id` も同じ名前に変えてください。

## 更新するとき

`sw.js` はキャッシュを優先するため、`index.html` などを変えたら `sw.js` の `CACHE` の番号も上げてください（例: `suno-lyric-factory-v2`）。番号を上げないと、利用者の端末に古い画面が残ります。

## 同じドメインの他のアプリとの関係

`bigfish60over-rin.github.io` の下のアプリは、キャッシュとlocalStorageを共有します。

- `sw.js` が古いキャッシュを消す対象は `suno-lyric-factory-` で始まる名前に限っています
- 他のアプリが全キャッシュを消す作りの場合、そのアプリの更新時にこのアプリのキャッシュも消えます。次にオンラインで開くと、開いた画面から再びキャッシュされます
